1. INLINE CSS

2. INTERNAL CSS (Embedded CSS)
   - Written inside <style> tag in the <head> section of HTML document
   - Applies to single HTML page only
   - Better than inline but not reusable across multiple pages

/* 
===========================================
NOTES & BEST PRACTICES
===========================================

1. CSS PRIORITY (Specificity Order):
   Inline CSS > Internal CSS > External CSS > Browser Default

2. WHEN TO USE EACH TYPE:
   - Inline: Quick testing, one-time unique styles (avoid in production)
   - Internal: Single-page websites, page-specific styles
   - External: Multi-page websites, maintainable projects (RECOMMENDED)

3. ADVANTAGES OF EXTERNAL CSS:
   ✓ Code reusability
   ✓ Easy maintenance
   ✓ Faster page loading (browser caching)
   ✓ Clean HTML code
   ✓ Consistent styling across website

4. CSS SELECTORS:
   - Element selector: p { }
   - Class selector: .classname { }
   - ID selector: #idname { }
   - Universal selector: * { }
   - Attribute selector: [type="text"] { }

5. COMMON CSS PROPERTIES:
   - color: text color
   - background-color: background color
   - font-size: text size
   - margin: outer spacing
   - padding: inner spacing
   - border: element border
   - display: element display type
   - position: element positioning

6. LINKING EXTERNAL CSS:
   <link rel="stylesheet" href="path/to/file.css">
   - rel: relationship (stylesheet)
   - href: path to CSS file

===========================================
*/

CSS Selectors are patterns used to select and target HTML elements that you want to style.

===========================================
TYPES OF CSS SELECTORS WITH EXAMPLES
===========================================
*/

/* 1. UNIVERSAL SELECTOR (*)
   - Selects ALL elements on the page
   - Used to apply global styles or reset default styles
*/
/* * {

}

/* 2. ELEMENT/TYPE SELECTOR
   - Selects all elements of a specific HTML tag
   - Targets elements by their tag name
*/
p {
    color: black;
    font-size: 16px;
}

h1 {
    font-size: 32px;
    font-weight: bold;
}

div {
    display: block;
}

/* 3. CLASS SELECTOR (.)
   - Selects elements with a specific class attribute
   - Can be applied to multiple elements
   - Reusable across different elements
*/
.button {
    background-color: blue;
    color: white;
    padding: 10px 20px;
}

.highlight {
    background-color: yellow;
}

.container {
    max-width: 1200px;
    margin: 0 auto;
}

/* 4. ID SELECTOR (#)
   - Selects a single element with a specific id attribute
   - Should be unique on the page
   - Higher specificity than class selector
*/
#header {
    background-color: navy;
    height: 80px;
}

#main-content {
    padding: 20px;
}

#footer {
    text-align: center;
}

/* 5. ATTRIBUTE SELECTOR
   - Selects elements based on their attributes or attribute values
*/

/* Selects all input elements with type="text" */
input[type="text"] {
    border: 1px solid gray;
    padding: 5px;
}

/* Selects all links with target="_blank" */
a[target="_blank"] {
    color: red;
}

/* Selects elements with title attribute */
[title] {
    cursor: help;
}

/* 6. DESCENDANT SELECTOR (space)
   - Selects elements that are descendants of another element
   - Doesn't have to be direct child
*/
div p {
    color: green;
}

.container h2 {
    margin-bottom: 15px;
}

/* 7. CHILD SELECTOR (>)
   - Selects direct children only
   - More specific than descendant selector
*/
ul > li {
    list-style-type: square;
}

div > p {
    font-weight: bold;
}

/* 8. ADJACENT SIBLING SELECTOR (+)
   - Selects element immediately following another element
   - Must be at the same level and directly after
*/
h1 + p {
    font-size: 18px;
    color: gray;
}

/* 9. GENERAL SIBLING SELECTOR (~)
   - Selects all siblings that follow an element
   - Same level but doesn't have to be immediately after
*/
h2 ~ p {
    color: darkblue;
}

/* 10. GROUPING SELECTOR (,)
    - Applies same styles to multiple selectors
    - Reduces code repetition
*/
h1, h2, h3 {
    font-family: Arial, sans-serif;
    color: #333;
}

.button, .link, .submit {
    cursor: pointer;
}

/* 11. PSEUDO-CLASS SELECTOR (:)
    - Selects elements in a specific state
*/

/* Hover state */
a:hover {
    color: red;
    text-decoration: underline;
}

/* First child */
li:first-child {
    font-weight: bold;
}

/* Last child */
li:last-child {
    border-bottom: none;
}

/* Nth child */
tr:nth-child(even) {
    background-color: #f2f2f2;
}

/* Focus state */
input:focus {
    border-color: blue;
    outline: none;
}

/* 12. PSEUDO-ELEMENT SELECTOR (::)
    - Selects and styles a specific part of an element
*/

/* First letter */
p::first-letter {
    font-size: 2em;
    font-weight: bold;
}

/* First line */
p::first-line {
    color: blue;
}

/* Before element */
.quote::before {
    content: '"';
    font-size: 24px;
}

/* After element */

    content: '"';
    font-size: 24px;
}

/* 
===========================================
SELECTOR SPECIFICITY (Priority Order)
===========================================

From HIGHEST to LOWEST priority:
1. Inline styles (style attribute)
2. ID selectors (#id)
3. Class selectors (.class), Attribute selectors, Pseudo-classes
4. Element selectors (tag), Pseudo-elements
5. Universal selector (*)

Example:
If both rules apply to same element, the more specific one wins:
#header { color: blue; }     /* More specific - WINS */
.header { color: red; }      /* Less specific */

===========================================
BEST PRACTICES
===========================================

1. Use class selectors for reusable styles
2. Use ID selectors sparingly (only for unique elements)
3. Avoid overly specific selectors (hard to override)
4. Keep selectors simple and readable
5. Use grouping to reduce code repetition
6. Prefer classes over IDs for styling
7. Use semantic class names (.button, .header, not .blue, .big)

===========================================
*/


/* 
===========================================
CSS BOX MODEL - DETAILED EXPLANATION
===========================================

The CSS Box Model is a fundamental concept that describes how every HTML element is represented as a rectangular box.
Each box consists of four areas: content, padding, border, and margin.

Understanding the box model is crucial for controlling layout, spacing, and sizing of elements on a web page.

===========================================
COMPONENTS OF THE BOX MODEL (from inside to outside)
===========================================

1. CONTENT
   - The actual content of the element (text, images, etc.)
   - Defined by width and height properties
   - This is where your text or images appear

2. PADDING
   - Space between the content and the border
   - Inside the element
   - Inherits the background color of the element
   - Can be set individually for each side (top, right, bottom, left)

3. BORDER
   - A line that surrounds the padding and content
   - Can have different styles, widths, and colors
   - Sits between padding and margin

4. MARGIN
   - Space outside the border
   - Creates distance between elements
   - Transparent (doesn't inherit background color)
   - Can be set individually for each side

===========================================
VISUAL REPRESENTATION
===========================================

+------------------------------------------+
|              MARGIN (transparent)         |
|  +------------------------------------+  |
|  |         BORDER                     |  |
|  |  +------------------------------+  |  |
|  |  |      PADDING                 |  |  |
|  |  |  +------------------------+  |  |  |
|  |  |  |                        |  |  |  |
|  |  |  |       CONTENT          |  |  |  |
|  |  |  |    (width x height)    |  |  |  |
|  |  |  |                        |  |  |  |
|  |  |  +------------------------+  |  |  |
|  |  |                              |  |  |
|  |  +------------------------------+  |  |
|  |                                    |  |
|  +------------------------------------+  |
|                                          |
+------------------------------------------+

===========================================
BOX MODEL PROPERTIES - SYNTAX & EXAMPLES
===========================================
*/

/* CONTENT - Width and Height */
.box {
    width: 300px;
    height: 200px;
}

/* PADDING - Space inside the element */
.box-padding {
    /* All sides */
    padding: 20px;
    
    /* Individual sides */
    padding-top: 10px;
    padding-right: 15px;
    padding-bottom: 10px;
    padding-left: 15px;
    
    /* Shorthand (top, right, bottom, left) */
    padding: 10px 15px 10px 15px;
    
    /* Shorthand (top/bottom, left/right) */
    padding: 10px 15px;
}

/* BORDER - Line around the element */
.box-border {
    /* All properties together */
    border: 2px solid black;
    
    /* Individual properties */
    border-width: 2px;
    border-style: solid;  /* solid, dashed, dotted, double, none */
    border-color: black;
    
    /* Individual sides */
    border-top: 1px solid red;
    border-right: 2px dashed blue;
    border-bottom: 3px dotted green;
    border-left: 4px double orange;
    
    /* Border radius (rounded corners) */
    border-radius: 10px;
}

/* MARGIN - Space outside the element */
.box-margin {
    /* All sides */
    margin: 20px;
    
    /* Individual sides */
    margin-top: 10px;
    margin-right: 15px;
    margin-bottom: 10px;
    margin-left: 15px;
    
    /* Shorthand (top, right, bottom, left) */
    margin: 10px 15px 10px 15px;
    
    /* Shorthand (top/bottom, left/right) */
    margin: 10px 15px;
    
    /* Center element horizontally */
    margin: 0 auto;
}

/* 
===========================================
BOX-SIZING PROPERTY
===========================================

By default, width and height only apply to the content area.
Padding and border are ADDED to the total size.

Example with default box-sizing:
width: 300px + padding: 20px + border: 5px = Total width: 350px

box-sizing property changes this behavior:
*/

/* DEFAULT: content-box */
.default-box {
    box-sizing: content-box;  /* width/height applies to content only */
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    /* Total width = 300 + 40 (padding) + 10 (border) = 350px */
}

/* RECOMMENDED: border-box */
.border-box {
    box-sizing: border-box;  /* width/height includes padding and border */
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    /* Total width = 300px (padding and border included) */
}

/* Global reset (recommended best practice) */
* {
    box-sizing: border-box;
}

/* 
===========================================
COMPLETE EXAMPLE WITH ALL BOX MODEL PROPERTIES
===========================================
*/

.complete-box {

    width: 300px;

    /* Padding */
    padding: 20px;
    
    /* Border */
    border: 3px solid #333;
    border-radius: 8px;
    
    /* Margin */
    margin: 30px;
    
    /* Box sizing */
    box-sizing: border-box;

/* 
===========================================
CALCULATING TOTAL ELEMENT SIZE
===========================================

WITHOUT box-sizing: border-box (default):
Total Width = width + padding-left + padding-right + border-left + border-right
Total Height = height + padding-top + padding-bottom + border-top + border-bottom

Example:
width: 300px
padding: 20px (all sides)
border: 5px (all sides)

Total Width = 300 + 20 + 20 + 5 + 5 = 350px
Total Height = 200 + 20 + 20 + 5 + 5 = 250px

WITH box-sizing: border-box:
Total Width = width (padding and border included)
Total Height = height (padding and border included)

Same example:
Total Width = 300px
Total Height = 200px

Note: Margin is NEVER included in the element's total size calculation

===========================================
COMMON BOX MODEL ISSUES & SOLUTIONS
===========================================

1. MARGIN COLLAPSE
   - Vertical margins between elements can collapse (merge)
   - The larger margin wins
   - Solution: Use padding instead, or add border/padding to parent

2. UNEXPECTED ELEMENT SIZE
   - Forgetting that padding and border add to width/height
   - Solution: Use box-sizing: border-box

3. CENTERING ELEMENTS
   - Use margin: 0 auto; for horizontal centering
   - Element must have a defined width
   - Only works for block-level elements

4. NEGATIVE MARGINS
   - Can be used to overlap elements
   - margin: -10px; pulls element in opposite direction

===========================================
BEST PRACTICES
===========================================

1. Always use box-sizing: border-box (apply globally with *)
2. Use margin for spacing between elements
3. Use padding for spacing inside elements
4. Be consistent with spacing values (use multiples of 4 or 8)
5. Use shorthand properties to reduce code
6. Remember: margin is transparent, padding inherits background
7. Use browser DevTools to inspect and debug box model
8. Consider using CSS variables for consistent spacing

===========================================
SHORTHAND SYNTAX REFERENCE
===========================================

One value:
padding: 10px;  /* all sides */

Two values:
padding: 10px 20px;  /* top/bottom left/right */

Three values:
padding: 10px 20px 15px;  /* top left/right bottom */

Four values:
padding: 10px 20px 15px 25px;  /* top right bottom left (clockwise) */

Same applies to: margin, padding, border-width, border-style, border-color

===========================================
*/
