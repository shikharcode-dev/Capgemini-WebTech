# ORDERED AND UNORDERED LISTS - NOTES

## ORDERED LISTS (OL)
# - Lists where the order of items matters
# - Items are numbered automatically
# - Used when sequence or priority is important
# - Syntax: <ol> tag with <li> items inside

# Example of Ordered List:
# <ol>
#   <li>First step: Gather ingredients</li>
#   <li>Second step: Mix ingredients</li>
#   <li>Third step: Bake for 30 minutes</li>
# </ol>
# Output:
# 1. First step: Gather ingredients
# 2. Second step: Mix ingredients
# 3. Third step: Bake for 30 minutes

## UNORDERED LISTS (UL)
# - Lists where the order doesn't matter
# - Items are marked with bullets (•)
# - Used for grouping related items without sequence
# - Syntax: <ul> tag with <li> items inside

# Example of Unordered List:
# <ul>
#   <li>Apples</li>
#   <li>Bananas</li>
#   <li>Oranges</li>
# </ul>
# Output:
# • Apples
# • Bananas
# • Oranges

## KEY DIFFERENCES
# - Ordered: Numbers (1, 2, 3...)
# - Unordered: Bullets (•, ◦, ▪)
# - Ordered: Sequence matters
# - Unordered: No specific order required

## NESTED LISTS EXAMPLE
# <ul>
#   <li>Fruits
#     <ol>
#       <li>Apple</li>
#       <li>Banana</li>
#     </ol>
#   </li>
#   <li>Vegetables</li>
# </ul> 



# ATTRIBUTES FOR ORDERED AND UNORDERED LISTS - DETAILED NOTES

## ORDERED LIST (<ol>) ATTRIBUTES

# 1. type attribute - Specifies the numbering style
#    Values: "1" (numbers), "A" (uppercase letters), "a" (lowercase letters), 
#            "I" (uppercase Roman), "i" (lowercase Roman)
#    Example:
#    <ol type="A">
#      <li>First item</li>
#      <li>Second item</li>
#    </ol>
#    Output: A. First item, B. Second item

# 2. start attribute - Defines the starting number/letter
#    Value: Any positive integer
#    Example:
#    <ol start="5">
#      <li>Item five</li>
#      <li>Item six</li>
#    </ol>
#    Output: 5. Item five, 6. Item six

# 3. reversed attribute - Reverses the numbering order (descending)
#    Value: Boolean (no value needed, presence activates it)
#    Example:
#    <ol reversed>
#      <li>Third</li>
#      <li>Second</li>
#      <li>First</li>
#    </ol>
#    Output: 3. Third, 2. Second, 1. First

## UNORDERED LIST (<ul>) ATTRIBUTES

# 1. type attribute (deprecated in HTML5, use CSS instead)
#    Values: "disc" (filled circle), "circle" (hollow circle), "square"
#    Example:
#    <ul type="square">
#      <li>Item one</li>
#      <li>Item two</li>
#    </ul>
#    Output: ▪ Item one, ▪ Item two

## LIST ITEM (<li>) ATTRIBUTES

# 1. value attribute - Sets a specific number for that item (only in <ol>)
#    Value: Integer
#    Example:
#    <ol>
#      <li>First</li>
#      <li value="10">Tenth</li>
#      <li>Eleventh</li>
#    </ol>
#    Output: 1. First, 10. Tenth, 11. Eleventh

# 2. type attribute - Overrides parent list type for specific item
#    Example:
#    <ol>
#      <li>Normal number</li>
#      <li type="A">Uppercase letter</li>
#      <li>Back to number</li>
#    </ol>
#    Output: 1. Normal number, B. Uppercase letter, 3. Back to number

## COMMON GLOBAL ATTRIBUTES (applicable to all list elements)

# 1. id - Unique identifier for the element
#    Example: <ul id="main-menu">

# 2. class - CSS class name(s) for styling
#    Example: <ol class="recipe-steps important">

# 3. style - Inline CSS styling
#    Example: <ul style="list-style-type: none;">

# 4. title - Tooltip text on hover
#    Example: <li title="Click for more info">Item</li>

## PRACTICAL EXAMPLES WITH MULTIPLE ATTRIBUTES

# Example 1: Recipe with custom numbering
# <ol type="1" start="1" class="recipe">
#   <li>Preheat oven to 350°F</li>
#   <li>Mix dry ingredients</li>
#   <li value="5">Bake for 25 minutes</li>
# </ol>

# Example 2: Countdown list
# <ol reversed start="10">
#   <li>Ten</li>
#   <li>Nine</li>
#   <li>Eight</li>
# </ol>
# Output: 10. Ten, 9. Nine, 8. Eight

# Example 3: Mixed type list
# <ol>
#   <li type="1">First in numbers</li>
#   <li type="A">Second in letters</li>
#   <li type="i">Third in Roman</li>
# </ol>
# Output: 1. First in numbers, B. Second in letters, iii. Third in Roman



# COMPREHENSIVE EXPLANATION OF HTML LIST ATTRIBUTES

# HTML lists support various attributes that control their appearance and behavior.
# These attributes can be categorized into three main groups:
# 1. Ordered List (<ol>) specific attributes
# 2. Unordered List (<ul>) specific attributes  
# 3. List Item (<li>) attributes
# 4. Global attributes (applicable to all HTML elements including lists)

# DETAILED BREAKDOWN OF EACH ATTRIBUTE TYPE:

# === ORDERED LIST (<ol>) ATTRIBUTES ===

# 1. TYPE ATTRIBUTE:
#    - Purpose: Controls the numbering/lettering style of list items
#    - Possible values:
#      * "1" = Decimal numbers (1, 2, 3, 4...) - DEFAULT
#      * "A" = Uppercase letters (A, B, C, D...)
#      * "a" = Lowercase letters (a, b, c, d...)
#      * "I" = Uppercase Roman numerals (I, II, III, IV...)
#      * "i" = Lowercase Roman numerals (i, ii, iii, iv...)
#    - Use case: When you need different numbering systems (legal docs, outlines)

# 2. START ATTRIBUTE:
#    - Purpose: Defines which number/letter the list begins counting from
#    - Value: Any positive integer (even when using letters or Roman numerals)
#    - Example: start="5" with type="A" gives you E, F, G...
#    - Use case: Continuing numbered lists across multiple sections

# 3. REVERSED ATTRIBUTE:
#    - Purpose: Makes the list count backwards (descending order)
#    - Value: Boolean attribute (no value needed, just its presence activates it)
#    - Works with all type values
#    - Use case: Countdown lists, rankings from bottom to top

# === UNORDERED LIST (<ul>) ATTRIBUTES ===

# 1. TYPE ATTRIBUTE (DEPRECATED):
#    - Purpose: Sets the bullet point style
#    - Possible values:
#      * "disc" = Filled circle (•) - DEFAULT
#      * "circle" = Hollow circle (○)
#      * "square" = Filled square (▪)
#    - Note: Deprecated in HTML5; use CSS list-style-type property instead
#    - Use case: Quick bullet style changes (though CSS is preferred)

# === LIST ITEM (<li>) ATTRIBUTES ===

# 1. VALUE ATTRIBUTE:
#    - Purpose: Manually sets the number for a specific list item
#    - Only works inside <ol> (ordered lists)
#    - Value: Integer
#    - Subsequent items continue counting from this new value
#    - Use case: Skipping numbers, creating gaps in sequences

# 2. TYPE ATTRIBUTE:
#    - Purpose: Overrides the parent list's type for just this one item
#    - Can be used in both <ol> and <ul>
#    - Values: Same as parent list type values
#    - Use case: Highlighting special items with different numbering

# === GLOBAL ATTRIBUTES (work on <ol>, <ul>, and <li>) ===

# 1. ID ATTRIBUTE:
#    - Purpose: Assigns a unique identifier to the element
#    - Value: String (must be unique in the document)
#    - Use case: JavaScript targeting, CSS styling, anchor links

# 2. CLASS ATTRIBUTE:
#    - Purpose: Assigns one or more CSS class names
#    - Value: Space-separated class names
#    - Use case: Applying CSS styles, JavaScript selection

# 3. STYLE ATTRIBUTE:
#    - Purpose: Applies inline CSS directly to the element
#    - Value: CSS property-value pairs
#    - Use case: Quick styling without external CSS (not recommended for large projects)

# 4. TITLE ATTRIBUTE:
#    - Purpose: Provides advisory information (tooltip on hover)
#    - Value: Text string
#    - Use case: Adding helpful hints or additional context

# 5. LANG ATTRIBUTE:
#    - Purpose: Specifies the language of the element's content
#    - Value: Language code (e.g., "en", "es", "fr")
#    - Use case: Multilingual documents, accessibility

# 6. DIR ATTRIBUTE:
#    - Purpose: Sets text direction
#    - Values: "ltr" (left-to-right) or "rtl" (right-to-left)
#    - Use case: Languages like Arabic or Hebrew

# 7. DATA-* ATTRIBUTES:
#    - Purpose: Store custom data private to the page or application
#    - Value: Any string
#    - Example: data-category="fruits"
#    - Use case: JavaScript data storage, custom metadata

# === ATTRIBUTE INTERACTION EXAMPLES ===

# Example showing multiple attributes working together:
# <ol type="A" start="3" reversed class="priority-list" id="main-tasks">
#   <li value="10">Task at position J</li>
#   <li>Task at position I</li>
#   <li type="1">Task shown as number 8</li>
# </ol>

# This demonstrates:
# - type="A": Uses uppercase letters
# - start="3": Begins at C (third letter)
# - reversed: Counts backwards
# - value="10": Jumps to J (10th letter)
# - type="1": Overrides to show number instead of letter
# - class and id: For styling and JavaScript access


# HTML TABLES - COMPREHENSIVE GUIDE WITH DETAILED EXAMPLES

# ============================================================================
# WHAT IS AN HTML TABLE?
# ============================================================================
# A table is a structured set of data organized in rows and columns
# Tables are used to display tabular data in a grid format
# HTML tables are created using the <table> element along with related tags

# ============================================================================
# BASIC TABLE STRUCTURE
# ============================================================================
# Main elements required to create a table:
# 1. <table> - Container for the entire table
# 2. <tr> - Table Row (defines a row)
# 3. <td> - Table Data (defines a cell/column within a row)
# 4. <th> - Table Header (defines a header cell, bold and centered by default)

# ============================================================================
# BASIC TABLE EXAMPLE
# ============================================================================
# <table>
#   <tr>
#     <th>Name</th>
#     <th>Age</th>
#     <th>City</th>
#   </tr>
#   <tr>
#     <td>John</td>
#     <td>25</td>
#     <td>New York</td>
#   </tr>
#   <tr>
#     <td>Sarah</td>
#     <td>30</td>
#     <td>London</td>
#   </tr>
# </table>

# Output:
# | Name  | Age | City     |
# |-------|-----|----------|
# | John  | 25  | New York |
# | Sarah | 30  | London   |

# ============================================================================
# TABLE STRUCTURE ELEMENTS (SEMANTIC GROUPING)
# ============================================================================

# 1. <thead> - Table Head (groups header content)
# 2. <tbody> - Table Body (groups main content)
# 3. <tfoot> - Table Footer (groups footer content like totals)

# Example with semantic structure:
# <table>
#   <thead>
#     <tr>
#       <th>Product</th>
#       <th>Price</th>
#       <th>Quantity</th>
#     </tr>
#   </thead>
#   <tbody>
#     <tr>
#       <td>Laptop</td>
#       <td>$999</td>
#       <td>5</td>
#     </tr>
#     <tr>
#       <td>Mouse</td>
#       <td>$25</td>
#       <td>20</td>
#     </tr>
#   </tbody>
#   <tfoot>
#     <tr>
#       <td>Total</td>
#       <td>$1024</td>
#       <td>25</td>
#     </tr>
#   </tfoot>
# </table>

# ============================================================================
# TABLE ATTRIBUTES
# ============================================================================

# 1. BORDER ATTRIBUTE (deprecated, use CSS instead)
#    <table border="1"> - Adds border to table

# 2. CELLPADDING (deprecated, use CSS padding)
#    <table cellpadding="10"> - Space inside cells

# 3. CELLSPACING (deprecated, use CSS border-spacing)
#    <table cellspacing="5"> - Space between cells

# 4. WIDTH ATTRIBUTE
#    <table width="100%"> - Sets table width

# 5. ALIGN ATTRIBUTE (deprecated, use CSS)
#    <table align="center"> - Aligns table

# ============================================================================
# CELL SPANNING ATTRIBUTES
# ============================================================================

# 1. COLSPAN - Makes a cell span across multiple columns
#    Syntax: <td colspan="number">
#    Example:
#    <table border="1">
#      <tr>
#        <th colspan="3">Student Information</th>
#      </tr>
#      <tr>
#        <td>Name</td>
#        <td>Age</td>
#        <td>Grade</td>
#      </tr>
#    </table>
#    Output: "Student Information" spans across all 3 columns

# 2. ROWSPAN - Makes a cell span across multiple rows
#    Syntax: <td rowspan="number">
#    Example:
#    <table border="1">
#      <tr>
#        <td rowspan="2">John</td>
#        <td>Math</td>
#        <td>95</td>
#      </tr>
#      <tr>
#        <td>Science</td>
#        <td>88</td>
#      </tr>
#    </table>
#    Output: "John" spans across 2 rows

# ============================================================================

# 1. Always use <th> for headers with scope attribute
#    <th scope="col">Column Header</th>
#    <th scope="row">Row Header</th>

# 2. Use <caption> to describe table purpose

#    <table summary="Sales data by region and month">

# 2. Always include <thead> and <tbody> for better structure
# 3. Use <th> for headers to improve accessibility
# 4. colspan and rowspan help create complex table structures
# 5. Use CSS for styling instead of deprecated HTML attributes

# HTML FORMS - COMPREHENSIVE GUIDE
# ============================================================================

# WHAT IS AN HTML FORM?
# - HTML element that allows users to input data and submit it to a server
# - Used for: user registration, login, search, feedback, surveys, etc.
# - The <form> element acts as a container for various input elements

# ============================================================================
# BASIC FORM STRUCTURE
# ============================================================================
# <form action="submit.php" method="POST">
#   <input type="text" name="username">
#   <input type="submit" value="Submit">
# </form>

# Key attributes:
# - action: URL where form data is sent
# - method: HTTP method (GET or POST)
# - name: Identifier for the form
# - target: Where to display response (_blank, _self, etc.)

# ============================================================================
# TYPES OF FORMS (BY PURPOSE)
# ============================================================================
# 1. REGISTRATION FORMS - Creating new user accounts
# 2. LOGIN FORMS - User authentication
# 3. SEARCH FORMS - Searching content
# 4. CONTACT FORMS - Communication
# 5. SURVEY/FEEDBACK FORMS - Gathering opinions
# 6. PAYMENT FORMS - Transactions
# 7. UPLOAD FORMS - File uploads

# ============================================================================
# FORM INPUT TYPES
# ============================================================================

# TEXT INPUT - Single-line text entry
# <input type="text" name="username" placeholder="Enter username">

# PASSWORD INPUT - Masked text entry for sensitive data
# <input type="password" name="password" placeholder="Enter password">

# EMAIL INPUT - Validates email format
# <input type="email" name="email" placeholder="user@example.com">

# NUMBER INPUT - Numeric input with optional min/max
# <input type="number" name="age" min="1" max="100">

# DATE INPUT - Date picker
# <input type="date" name="birthdate">

# RADIO BUTTONS - Single selection from multiple options
# <input type="radio" name="gender" value="male"> Male
# <input type="radio" name="gender" value="female"> Female

# CHECKBOXES - Multiple selections allowed
# <input type="checkbox" name="hobbies" value="reading"> Reading
# <input type="checkbox" name="hobbies" value="sports"> Sports

# DROPDOWN/SELECT - Dropdown list of options
# <select name="country">
#   <option value="usa">USA</option>
#   <option value="uk">UK</option>
# </select>

# TEXTAREA - Multi-line text input
# <textarea name="message" rows="4" cols="50"></textarea>

# FILE INPUT - File upload

# ============================================================================
# FORM ATTRIBUTES
# ============================================================================
# action - URL where form data is sent
# method - GET (data visible in URL) or POST (data hidden in request body)
# enctype - application/x-www-form-urlencoded (default), multipart/form-data (for file uploads)
# target - _self (same window), _blank (new window/tab)
# autocomplete - on, off
# novalidate - Disable HTML5 validation

# ============================================================================
# INPUT ATTRIBUTES
# ============================================================================
# required - Makes field mandatory
# placeholder - Hint text
# value - Default value
# readonly - Cannot be edited
# disabled - Field is disabled
# maxlength - Maximum character length
# min/max - For number and date inputs
# pattern - Regular expression validation
# autofocus - Auto-focus on page load
# multiple - Allow multiple values (for file, email)

# ============================================================================
# HTML5 NEW INPUT TYPES
# ============================================================================
# type="email" - Email validation
# type="url" - URL validation
# type="tel" - Telephone number
# type="search" - Search field
# type="date" - Date picker
# type="time" - Time picker
# type="datetime-local" - Date and time
# type="month" - Month picker
# type="week" - Week picker
# type="color" - Color picker
# type="range" - Slider

# FORM VALIDATION
# ============================================================================

# - required attribute

# DIFFERENCE BETWEEN RADIO BUTTONS AND DROPDOWN (SIMPLE EXPLANATION)

# RADIO BUTTONS:
# - All options are visible on the screen at once
# - User can see all choices without clicking anything
# - Best for 2-5 options (small number of choices)
# - Takes more space on the page
# - Example: Selecting gender (Male/Female/Other)
# <input type="radio" name="gender" value="male"> Male
# <input type="radio" name="gender" value="female"> Female
# <input type="radio" name="gender" value="other"> Other

# DROPDOWN (SELECT):
# - Options are hidden until you click the dropdown
# - User must click to see all choices
# - Best for many options (6+ choices)
# - Takes less space on the page
# - Example: Selecting a country from 100+ countries
# <select name="country">
#   <option value="usa">USA</option>
#   <option value="uk">UK</option>
#   <option value="canada">Canada</option>
# </select>

# SIMPLE RULE:
# - Few options (2-5) → Use Radio Buttons
# - Many options (6+) → Use Dropdown
