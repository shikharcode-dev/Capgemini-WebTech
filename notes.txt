/* ABSOLUTE UNITS - Fixed size, not affected by other elements */

/* px (pixels) - Most common absolute unit */
div {

    height: 100px;
    font-size: 16px;

}

/* mm (millimeters) - Physical measurement */

    width: 50mm;
}

    width: 2in;
}

/* pc (picas) - 1pc = 12pt */
p {
    font-size: 1pc;
}


/* RELATIVE UNITS - Size relative to another value */
/* These units scale based on parent elements or viewport */

/* % (percentage) - Relative to parent element */
div {
    width: 50%; /* 50% of parent's width */
    font-size: 120%; /* 120% of parent's font-size */
}

/* em - Relative to parent element's font-size */
/* 1em = current font-size of parent */
p {
    font-size: 16px;
}
span {
    font-size: 2em; /* 2 × 16px = 32px */
    padding: 0.5em; /* 0.5 × 32px = 16px */
}

/* rem (root em) - Relative to root element's font-size */
/* More predictable than em, doesn't compound */
html {
    font-size: 16px;
}
h1 {
    font-size: 2rem; /* 2 × 16px = 32px */
}

/* vw (viewport width) - 1vw = 1% of viewport width */
div {
    width: 50vw; /* 50% of browser window width */
}

}

    width: 50vmin;
}

div {
    width: 50vmax;
}

/* ch - Width of the "0" character in current font */
input {
    width: 20ch; /* Width of 20 "0" characters */
}

/* ex - Height of lowercase "x" in current font */
sup {
    font-size: 1ex;
}


/* BEST PRACTICES */
/* Use px for borders, shadows, and fixed layouts */

/* Use rem for font-sizes (easier to scale entire site) */

JAVASCRIPT NOTES
================

1. TOKENS IN JAVASCRIPT
-----------------------

A token is the smallest meaningful unit of JavaScript code.

Tokens are the basic building blocks used to write and understand JavaScript statements.

Main types of JavaScript tokens:
1. Keywords
2. Identifiers
3. Variables
4. Literals
5. Constants
6. Data Types
7. Operators
8. Comments
9. Separators


2. KEYWORDS IN JAVASCRIPT
-------------------------

Keywords are words that are already defined by JavaScript.
Technically, they are called reserved words.

Examples:
for, if, switch, let, var, const, finally, catch, try, typeof, etc.

Keywords have a special/predefined meaning in JavaScript.

Example:
let age = 20;

Here, "let" is a keyword.

A keyword cannot normally be used as an identifier.

Example:
let if = 10;        // Invalid

Note:
The exact number of JavaScript keywords depends on the ECMAScript
version and on which reserved-word categories are being counted.
Do not treat "40 to 50" as an exact fixed number.


3. IDENTIFIERS
--------------

Identifiers are names used to identify programming elements.

They can be names of:
- Variables
- Functions
- Classes
- Objects
- Constants

Example:

let age = 20;

function calculate() {
}

Here:
age         -> Identifier
calculate   -> Identifier


4. RULES FOR NAMING IDENTIFIERS
-------------------------------

1. An identifier must NOT start with a digit.

Invalid:
let 2name = "Sam";

Valid:
let name2 = "Sam";


2. $ and _ can be used in identifiers.

Examples:
let $price = 500;
let _name = "Sam";


3. Spaces are NOT allowed in identifiers.

Invalid:
let first name = "Sam";

Valid:
let firstName = "Sam";
let first_name = "Sam";


4. JavaScript keywords cannot be used as identifiers.

Invalid:
let for = 10;
let class = "CSE";


5. Identifiers can contain letters, digits, $ and _.

Examples:
let student1 = "Sam";
let student_name = "Sam";
let student$name = "Sam";


6. Identifiers are case-sensitive.

Example:

let age = 20;
let Age = 30;
let AGE = 40;

age, Age and AGE are treated as different identifiers.

// VARIABLES IN JAVASCRIPT
// =======================

// A variable is a container/storage location that holds data/values in memory.
// Variables allow you to store, retrieve, and manipulate data in your program.

// WAYS TO CREATE VARIABLES IN JAVASCRIPT
// =======================================

// There are 3 ways to declare variables in JavaScript:

// 1. var (Old way - ES5 and earlier)
// -----------------------------------
var name = "John";
var age = 25;

// Characteristics of var:
// - Function-scoped (not block-scoped)
// - Can be re-declared
// - Can be updated
// - Hoisted to the top of their scope


// 2. let (Modern way - ES6/ES2015+)
// ----------------------------------
let city = "New York";
let price = 100;

// Characteristics of let:
// - Block-scoped
// - Cannot be re-declared in the same scope
// - Can be updated
// - Not hoisted (temporal dead zone)


// 3. const (Modern way for constants - ES6/ES2015+)
// -------------------------------------------------
const PI = 3.14159;
const country = "USA";

// Characteristics of const:
// - Block-scoped
// - Cannot be re-declared
// - Cannot be updated/reassigned
// - Must be initialized at declaration
// - Not hoisted (temporal dead zone)


// COMPARISON TABLE
// ================
// Feature          var         let         const
// -------          ---         ---         -----
// Scope            Function    Block       Block
// Re-declare       Yes         No          No
// Update           Yes         Yes         No
// Hoisting         Yes         No          No
// Initialize       Optional    Optional    Required


// BEST PRACTICES
// ==============
// - Use const by default
// - Use let when you need to reassign the variable
// - Avoid using var in modern JavaScript
