Notes: Web Basics and HTML

 What is a Webpage?
 - A webpage is a document displayed in a web browser
 - Contains text, images, videos, links, and other multimedia content
 - Part of a website (collection of related webpages)

 How to Access the Web
 - Requires an internet connection (WiFi, Ethernet, mobile data)
 - Requires a web browser (Chrome, Firefox, Safari, Edge, etc.)
 - Browser sends requests to web servers and displays the returned content

 HTML Overview
 - HTML = HyperText Markup Language
 - The fundamental language for creating webpages
 - Defines the structure and content of web documents
 - Uses tags and elements to organize information
 - Works together with CSS (styling) and JavaScript (interactivity)

 # Additional Definitions and Concepts

## What is a Website?
- A website is a collection of related webpages hosted on a web server
- All pages share a common domain name (e.g., example.com)
- Can contain multiple pages linked together for navigation
- Serves a specific purpose (information, entertainment, e-commerce, etc.)

## What is the Web?
- The Web (World Wide Web) is a system of interconnected documents and resources
- Accessed via the internet using URLs (web addresses)
- Allows users to navigate between pages using hyperlinks
- Created by Tim Berners-Lee in 1989

## What is the Internet?
- The Internet is a global network of interconnected computers
- Infrastructure that allows devices to communicate with each other
- The Web is just one service that runs on the Internet (others include email, file transfer, etc.)
- Uses protocols like TCP/IP to transmit data

## What is a Browser?
- A browser is software that retrieves and displays web content
- Examples: Chrome, Firefox, Safari, Edge, Opera
- Interprets HTML, CSS, and JavaScript to render webpages
- Sends HTTP/HTTPS requests to web servers and receives responses

## Purpose of HTML
- Provides structure and meaning to web content
- Defines elements like headings, paragraphs, links, images, etc.
- Creates the foundation that browsers can interpret and display
- Enables semantic markup for accessibility and SEO
- Acts as the skeleton of a webpage (CSS adds style, JavaScript adds behavior)

## What is HyperText?
- HyperText refers to text that contains links (hyperlinks) to other documents
- Allows non-linear navigation between documents
- The "HT" in HTML and HTTP (HyperText Transfer Protocol)
- Enables the interconnected nature of the Web

## What is a Markup Language?
- A markup language uses tags to annotate and structure content
- Tags tell the browser how to display or organize information
- HTML uses angle brackets: <tag>content</tag>, Inside the angular bracket
- Other examples: XML, Markdown
- Different from programming languages (doesn't have logic or calculations)
- Focuses on presentation and structure rather than functionality



# Frontend and Backend

## What is Frontend?
- Frontend refers to the client-side of a web application
- The part of the website that users see and interact with directly
- Runs in the user's web browser
- Focuses on user interface (UI) and user experience (UX)
- Also called "client-side development"

## What is Backend?
- Backend refers to the server-side of a web application
- The part that users don't see - runs on web servers
- Handles data storage, business logic, and server operations
- Manages databases, authentication, and server configuration
- Also called "server-side development"

## Technologies Required for Frontend
- **HTML** - Structure and content of webpages
- **CSS** - Styling and layout of webpages
- **JavaScript** - Interactivity and dynamic behavior
- **Frontend Frameworks/Libraries** (optional but common):
  - React, Angular, Vue.js
  - Bootstrap, Tailwind CSS (for styling)

## What is CSS?
- CSS = Cascading Style Sheets
- A language used to style and layout HTML elements
- Controls colors, fonts, spacing, positioning, and visual design
- Separates presentation from content
- Makes webpages visually appealing and responsive

## What is JavaScript?
- JavaScript is a programming language for web development
- Adds interactivity and dynamic behavior to webpages
- Can respond to user actions (clicks, typing, scrolling, etc.)
- Manipulates HTML and CSS in real-time
- Runs in the browser (frontend) and on servers (backend with Node.js)
- Different from Java - they are completely separate languages

# How to Install and Use Live Server in VS Code

## What is Live Server?
- Live Server is a VS Code extension that launches a local development server
- Automatically refreshes the browser when you save changes to your HTML/CSS/JS files
- Provides a better development experience than manually refreshing the browser
- Shows your webpage at a local URL (e.g., http://127.0.0.1:5500)

## Steps to Install Live Server

### Step 1: Open VS Code
- Launch Visual Studio Code on your computer

### Step 2: Open Extensions Panel
- Click on the Extensions icon in the left sidebar (or press Ctrl+Shift+X on Windows/Linux, Cmd+Shift+X on Mac)
- The Extensions icon looks like four squares with one separated

### Step 3: Search for Live Server
- Type "Live Server" in the search box at the top of the Extensions panel
- Look for the extension by Ritwick Dey (it has millions of downloads)

### Step 4: Install the Extension
- Click the "Install" button next to Live Server
- Wait for the installation to complete (usually takes a few seconds)
- The button will change to show it's installed

### Step 5: Reload VS Code (if needed)
- Sometimes VS Code may ask you to reload
- Click "Reload" if prompted, or close and reopen VS Code

## How to Use Live Server

### Method 1: Right-Click Method
1. Open your HTML file in VS Code
2. Right-click anywhere in the HTML file
3. Select "Open with Live Server" from the context menu
4. Your default browser will open automatically showing your webpage

### Method 2: Status Bar Method
1. Open your HTML file in VS Code
2. Look at the bottom-right corner of VS Code (status bar)
3. Click on "Go Live" button
4. Your webpage will open in the browser

### Method 3: Keyboard Shortcut
1. Open your HTML file in VS Code
2. Press Alt+L then Alt+O (Windows/Linux) or Cmd+L then Cmd+O (Mac)
3. The browser will launch with your webpage

## How Live Server Works
- Creates a local web server on your computer
- Serves your HTML files at http://127.0.0.1:5500 (or similar port)
- Watches for file changes in your project
- Automatically refreshes the browser when you save changes
- No need to manually refresh the browser after editing code

## How to Stop Live Server
- Click "Port: 5500" in the status bar at the bottom-right
- Or right-click in the HTML file and select "Stop Live Server"
- Or close the browser tab (server continues running in background)

## Benefits of Using Live Server
- Saves time - no manual browser refresh needed
- Instant feedback when you make changes
- Works with HTML, CSS, and JavaScript files
- Easy to use and configure
- Free and open-source

## Troubleshooting Tips
- If Live Server doesn't work, make sure you have an HTML file open
- Check that the file is saved with .html extension
- Try restarting VS Code if the extension doesn't appear
- Make sure no other program is using port 5500
- Check your firewall settings if the browser doesn't open

# What is a Tag?

## Definition
A tag is a fundamental building block of HTML that tells the browser how to structure and display content. Tags are predefined keywords or words that are wrapped in angular brackets (< >).

## Structure of Tags
- Tags use angular brackets: < and >
- The tag name goes between these brackets
- Example: <tagname>

## Types of Tags

### 1. Opening Tags
- Written as: <tagname>
- Marks the beginning of an element
- Example: <p>, <div>, <h1>

### 2. Closing Tags
- Written as: </tagname>
- Has a forward slash (/) before the tag name
- Marks the end of an element
- Example: </p>, </div>, </h1>

### 3. Self-Closing Tags (Empty Tags)
- Tags that don't need a closing tag
- Can be written as: <tagname> or <tagname />
- Examples: <br>, <img>, <hr>, <input>, <meta>

## How Tags Work
- Most tags come in pairs: an opening tag and a closing tag
- Content goes between the opening and closing tags
- Format: <tagname>content</tagname>
- Example: <h1>Hello World</h1>
  - <h1> is the opening tag
  - Hello World is the content
  - </h1> is the closing tag

## Characteristics of Tags

### Predefined
- Tags are predefined by the HTML specification
- You cannot create your own tag names (in standard HTML)
- Each tag has a specific purpose and meaning
- Browsers know how to interpret these predefined tags

### Case-Insensitive
- HTML tags are not case-sensitive
- <HTML>, <html>, and <HtMl> are all the same
- However, lowercase is the standard convention and best practice

### Must Use Angular Brackets
- Tags must always be enclosed in < and >
- Without angular brackets, the browser treats it as regular text
- Example: "p" is just text, but <p> is a tag

## Common HTML Tags and Their Purposes

### Structure Tags
- <html> - Root element of the page
- <head> - Contains metadata
- <body> - Contains visible content
- <div> - Generic container for grouping content
- <span> - Inline container for text

### Text Content Tags
- <h1> to <h6> - Headings (h1 is largest, h6 is smallest)
- <p> - Paragraph
- <br> - Line break
- <hr> - Horizontal rule (line)
- <strong> - Bold/important text
- <em> - Italic/emphasized text

### Link and Media Tags
- <a> - Hyperlink (anchor)
- <img> - Image
- <video> - Video content
- <audio> - Audio content

### List Tags
- <ul> - Unordered list (bullet points)
- <ol> - Ordered list (numbered)
- <li> - List item

### Table Tags
- <table> - Table container
- <tr> - Table row
- <td> - Table data cell
- <th> - Table header cell

### Form Tags
- <form> - Form container
- <input> - Input field
- <button> - Button
- <textarea> - Multi-line text input
- <select> - Dropdown menu

## Tag Attributes
- Tags can have attributes that provide additional information
- Attributes are written inside the opening tag
- Format: <tagname attribute="value">
- Example: <img src="photo.jpg" alt="A photo">
  - src and alt are attributes
  - "photo.jpg" and "A photo" are their values

## Nesting Tags
- Tags can be placed inside other tags
- This is called nesting
- Proper nesting is important - tags must close in the reverse order they were opened
- Correct: <div><p>Text</p></div>
- Incorrect: <div><p>Text</div></p>

## Why Tags Use Angular Brackets
- Angular brackets distinguish tags from regular text content
- They signal to the browser: "this is an instruction, not content to display"
- Without brackets, the browser would show the tag names as text
- The < and > symbols are reserved characters in HTML for this purpose

# What is Search Engine Optimization (SEO)?

## Definition
- SEO (Search Engine Optimization) is the practice of improving a website to increase its visibility in search engine results
- When people search for topics related to your website, SEO helps your site appear higher in search results
- Higher rankings lead to more organic (non-paid) traffic to your website
- SEO involves optimizing both the technical aspects and content of your website

## Why SEO is Important
- Most web traffic comes from search engines (Google, Bing, Yahoo, etc.)
- Users rarely look beyond the first page of search results
- Higher rankings = more visibility = more visitors = more potential customers/readers
- Builds credibility and trust (users trust sites that rank higher)
- Cost-effective compared to paid advertising
- Long-term benefits (good SEO continues to work over time)

## How Search Engines Work

### 1. Crawling
- Search engines use bots (called "crawlers" or "spiders") to discover web pages
- Crawlers follow links from page to page across the internet
- They download and store information about each page they find

### 2. Indexing
- Search engines analyze and store the crawled pages in a massive database (index)
- They categorize content based on keywords, topics, and relevance
- Not all pages are indexed (some may be blocked or deemed low-quality)

### 3. Ranking
- When a user searches, the search engine retrieves relevant pages from its index
- Pages are ranked based on hundreds of factors (relevance, quality, authority, etc.)
- The most relevant and high-quality pages appear at the top of results

## HTML Elements Important for SEO

### 1. Title Taghtml
<title>Best Pizza in New York | Joe's Pizza Shop</title>- Appears in browser tabs and search results
- Should be 50-60 characters long
- Include main keywords naturally
- Make it descriptive and compelling
- Each page should have a unique title

### 2. Meta Descriptionhtml
<meta name="description" content="Joe's Pizza Shop serves authentic New York-style pizza with fresh ingredients. Visit us for the best pizza experience in Manhattan.">- Brief summary of the page (150-160 characters)
- Appears below the title in search results
- Doesn't directly affect rankings but influences click-through rates
- Should include relevant keywords and a call-to-action

### 3. Heading Tags (H1-H6)html
<h1>Welcome to Joe's Pizza Shop</h1>
<h2>Our Menu</h2>
<h3>Classic Pizzas</h3>
<h3>Specialty Pizzas</h3>
<h2>About Us</h2>- H1 is the most important heading (use only one per page)
- H2-H6 create a hierarchical structure
- Include keywords naturally in headings
- Help search engines understand page structure and content

### 4. Alt Text for Imageshtml
<img src="margherita-pizza.jpg" alt="Fresh margherita pizza with basil and mozzarella">- Describes images for search engines and screen readers
- Helps images appear in image search results
- Important for accessibility
- Use descriptive, keyword-rich text

### 5. Semantic HTML Tagshtml
<header>Site header content</header>
<nav>Navigation menu</nav>
<main>Main content</main>
<article>Blog post or article</article>
<section>Section of content</section>
<aside>Sidebar content</aside>
<footer>Footer content</footer>- Help search engines understand the purpose of different page sections
- Improve accessibility and code organization
- Better than using generic <div> tags everywhere

### 6. Anchor Tags with Descriptive Texthtml
<!-- Good for SEO -->
<a href="menu.html">View our complete pizza menu</a>

<!-- Bad for SEO -->
<a href="menu.html">Click here</a>- Use descriptive link text that tells users and search engines what to expect
- Avoid generic phrases like "click here" or "read more"
- Internal links help search engines discover and understand your site structure

## Robots Meta Tag

### What is the Robots Meta Tag?
- A meta tag that tells search engine crawlers how to interact with a specific page
- Placed in the <head> section of HTML
- Controls whether a page should be indexed and whether links should be followed

### Basic Syntaxhtml
<meta name="robots" content="index, follow">
### Common Robots Meta Tag Values

#### 1. index / noindexhtml
<!-- Allow search engines to index this page -->
<meta name="robots" content="index">

<!-- Prevent search engines from indexing this page -->
<meta name="robots" content="noindex">- **index**: Page can appear in search results (default behavior)
- **noindex**: Page should not appear in search results
- Use noindex for: login pages, admin pages, duplicate content, private pages

#### 2. follow / nofollowhtml
<!-- Allow search engines to follow links on this page -->
<meta name="robots" content="follow">

<!-- Prevent search engines from following links on this page -->
<meta name="robots" content="nofollow">- **follow**: Crawlers can follow links to discover other pages (default)
- **nofollow**: Crawlers should not follow links on this page
- Use nofollow for: untrusted content, paid links, user-generated content

#### 3. Combined Valueshtml
<!-- Most permissive (default behavior) -->
<meta name="robots" content="index, follow">

<!-- Don't index but follow links -->
<meta name="robots" content="noindex, follow">

<!-- Index but don't follow links -->
<meta name="robots" content="index, nofollow">

<!-- Most restrictive -->
<meta name="robots" content="noindex, nofollow">
#### 4. Additional Directiveshtml
<!-- Prevent showing cached version of page -->
<meta name="robots" content="noarchive">

<!-- Prevent showing snippet in search results -->
<meta name="robots" content="nosnippet">

<!-- Prevent indexing images on this page -->
<meta name="robots" content="noimageindex">

<!-- Don't show a translation in search results -->
<meta name="robots" content="notranslate">
### Targeting Specific Search Engineshtml
<!-- Only for Google -->
<meta name="googlebot" content="noindex, nofollow">

<!-- Only for Bing -->
<meta name="bingbot" content="noindex, nofollow">

<!-- For all search engines -->
<meta name="robots" content="noindex, nofollow">
## Robots.txt File

### What is robots.txt?
- A text file placed in the root directory of your website
- Tells search engine crawlers which pages or sections they can or cannot access
- Located at: www.yoursite.com/robots.txt
- Different from robots meta tag (robots.txt affects entire site, meta tag affects individual pages)

### Basic robots.txt Syntax
User-agent: *
Disallow: /admin/
Disallow: /private/
Allow: /public/

Sitemap: https://www.yoursite.com/sitemap.xml
### robots.txt Examples
# Block all crawlers from entire site
User-agent: *
Disallow: /

# Allow all crawlers to access everything
User-agent: *
Disallow:

# Block specific folders
User-agent: *
Disallow: /admin/
Disallow: /login/
Disallow: /cart/

# Block specific crawler (e.g., bad bot)
User-agent: BadBot
Disallow: /

# Allow Google but block others
User-agent: Googlebot
Disallow:

User-agent: *
Disallow: /
## Canonical Tags

### What is a Canonical Tag?
- Tells search engines which version of a page is the "main" or "preferred" version
- Prevents duplicate content issues
- Used when the same content appears at multiple URLs

### Canonical Tag Syntaxhtml
<link rel="canonical" href="https://www.example.com/preferred-page.html">
### When to Use Canonical Tagshtml
<!-- Original page -->
<!-- URL: https://www.example.com/products/shoes -->
<link rel="canonical" href="https://www.example.com/products/shoes">

<!-- Duplicate with tracking parameters -->
<!-- URL: https://www.example.com/products/shoes?utm_source=email -->
<link rel="canonical" href="https://www.example.com/products/shoes">

<!-- Duplicate with session ID -->
<!-- URL: https://www.example.com/products/shoes?sessionid=12345 -->
<link rel="canonical" href="https://www.example.com/products/shoes">

## XML Sitemap

### What is an XML Sitemap?
- A file that lists all important pages on your website
- Helps search engines discover and crawl your pages more efficiently
- Located at: www.yoursite.com/sitemap.xml

### Basic Sitemap Structurexml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://www.example.com/</loc>
    <lastmod>2024-01-15</lastmod>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://www.example.com/menu</loc>
    <lastmod>2024-01-10</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
  <url>
    <loc>https://www.example.com/about</loc>
    <lastmod>2024-01-01</lastmod>
    <changefreq>monthly</changefreq>
    <priority>0.5</priority>
  </url>
</urlset>
### Sitemap Elements Explained
- **loc**: The URL of the page (required)
- **lastmod**: Last modification date (optional)
- **changefreq**: How often the page changes (optional)
  - Values: always, hourly, daily, weekly, monthly, yearly, never
- **priority**: Importance relative to other pages (0.0 to 1.0, optional)

## Page Speed and Performance

### Why Page Speed Matters for SEO
- Google uses page speed as a ranking factor
- Slow pages lead to higher bounce rates
- Users expect pages to load in under 3 seconds
- Mobile speed is especially important

### HTML Techniques for Better Performancehtml
<!-- 1. Optimize images with proper attributes -->
<img src="pizza.jpg" alt="Pizza" width="800" height="600" loading="lazy">

<!-- 2. Use lazy loading for images below the fold -->
<img src="image.jpg" alt="Description" loading="lazy">

<!-- 3. Preload critical resources -->
<link rel="preload" href="critical-style.css" as="style">
<link rel="preload" href="important-font.woff2" as="font" type="font/woff2" crossorigin>

<!-- 4. Defer non-critical JavaScript -->
<script src="analytics.js" defer></script>

<!-- 5. Use async for independent scripts -->
<script src="ads.js" async></script>

<!-- 6. Minimize render-blocking CSS -->
<link rel="stylesheet" href="styles.css" media="print" onload="this.media='all'">

## URL Structure Best Practices

### Good URL Structure
✓ https://www.example.com/menu/pizza
✓ https://www.example.com/blog/how-to-make-pizza
✓ https://www.example.com/locations/new-york
### Poor URL Structure
✗ https://www.example.com/page?id=12345
✗ https://www.example.com/index.php?category=2&item=45
✗ https://www.example.com/MENU/Pizza.HTML
### URL Best Practices
- Use hyphens (-) instead of underscores (_)
- Keep URLs short and descriptive
- Use lowercase letters
- Include relevant keywords
- Avoid special characters and parameters when possible
- Use HTTPS (secure connection)

# Types of Tags - Detailed Notes

## What is a Tag?
- A tag is a fundamental building block of HTML
- Tags are predefined keywords wrapped in angular brackets (< >)
- They tell the browser how to structure and display content
- Tags are instructions that browsers interpret to render webpages

## The Three Main Types of Tags

### 1. Paired Tags (Container Tags)
- **Definition**: Tags that come in pairs with an opening tag and a closing tag
- **Structure**: <tagname>content</tagname>
- **Purpose**: Wrap around content to apply formatting or structure
- **Characteristics**:
  - Opening tag: <tagname>
  - Closing tag: </tagname> (has a forward slash before the tag name)
  - Content goes between the opening and closing tags
  - Must be properly nested (closed in reverse order of opening)

- **Common Examples**:
  - `<p>This is a paragraph</p>` - Paragraph tag
  - `<h1>Main Heading</h1>` - Heading tag
  - `<div>Container content</div>` - Division/container tag
  - `<span>Inline text</span>` - Inline container tag
  - `<a href="page.html">Link text</a>` - Anchor/link tag
  - `<strong>Bold text</strong>` - Strong/bold tag
  - `<em>Italic text</em>` - Emphasis/italic tag
  - `<ul><li>List item</li></ul>` - List tags
  - `<table><tr><td>Cell</td></tr></table>` - Table tags

- **Why Paired Tags Exist**:
  - They define where formatting starts and ends
  - They create a clear boundary for content
  - They allow nesting of elements for complex structures
  - They help browsers understand document hierarchy

### 2. Self-Closing Tags (Empty Tags / Void Tags)
- **Definition**: Tags that don't need a closing tag because they don't contain content
- **Structure**: <tagname> or <tagname /> (both are valid)
- **Purpose**: Insert standalone elements like images, line breaks, or metadata
- **Characteristics**:
  - No closing tag required
  - Cannot contain content between tags
  - Often used for embedding media or creating breaks
  - May have attributes but no inner content

- **Common Examples**:
  - `<br>` or `<br />` - Line break (forces text to next line)
  - `<hr>` or `<hr />` - Horizontal rule (draws a horizontal line)
  - `<img src="photo.jpg" alt="Photo">` - Image tag
  - `<input type="text">` - Input field for forms
  - `<meta charset="UTF-8">` - Metadata tag
  - `<link rel="stylesheet" href="style.css">` - Links external resources
  - `<area>` - Defines clickable area in image map
  - `<base>` - Specifies base URL for relative links
  - `<col>` - Defines column properties in tables
  - `<embed>` - Embeds external content
  - `<source>` - Specifies media resources
  - `<track>` - Text tracks for video/audio
  - `<wbr>` - Word break opportunity

- **Why Self-Closing Tags Exist**:
  - They represent elements that are complete by themselves
  - They don't need to wrap around content
  - They make HTML more concise and readable
  - They insert objects or create effects without needing inner content

### 3. Comment Tags
- **Definition**: Special tags used to add notes in HTML code that browsers ignore
- **Structure**: `<!-- comment text -->`
- **Purpose**: Document code, leave notes for developers, temporarily disable code
- **Characteristics**:
  - Not displayed in the browser
  - Can span multiple lines
  - Useful for explaining code or leaving reminders
  - Can be used to temporarily "hide" code without deleting it

- **Examples**:
  ```html
  <!-- This is a single-line comment -->
  
  <!-- 
    This is a multi-line comment
    It can span several lines
    Very useful for longer explanations
  -->
  
  <!-- TODO: Add navigation menu here -->
  
  <!-- <p>This paragraph is commented out and won't display</p> -->
  ```

- **Why Comment Tags Exist**:
  - Help developers understand code later
  - Allow team collaboration with notes
  - Enable temporary code removal for testing
  - Document complex sections of code
  - Leave reminders for future updates

## Additional Tag Classifications

### By Function/Purpose:

#### Structural Tags
- Define the overall structure of the document
- Examples: `<html>`, `<head>`, `<body>`, `<header>`, `<footer>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<aside>`

#### Text Formatting Tags
- Control how text appears
- Examples: `<p>`, `<h1>-<h6>`, `<strong>`, `<em>`, `<u>`, `<s>`, `<mark>`, `<small>`, `<sub>`, `<sup>`

#### Semantic Tags
- Provide meaning about the content they contain
- Examples: `<article>`, `<section>`, `<nav>`, `<header>`, `<footer>`, `<aside>`, `<figure>`, `<figcaption>`, `<time>`, `<address>`

#### Media Tags
- Embed images, video, and audio
- Examples: `<img>`, `<video>`, `<audio>`, `<picture>`, `<source>`, `<track>`

#### Link and Navigation Tags
- Create hyperlinks and navigation
- Examples: `<a>`, `<nav>`, `<link>`

#### List Tags
- Create ordered and unordered lists
- Examples: `<ul>`, `<ol>`, `<li>`, `<dl>`, `<dt>`, `<dd>`

#### Table Tags
- Create data tables
- Examples: `<table>`, `<tr>`, `<td>`, `<th>`, `<thead>`, `<tbody>`, `<tfoot>`, `<caption>`, `<col>`, `<colgroup>`

#### Form Tags
- Create interactive forms
- Examples: `<form>`, `<input>`, `<textarea>`, `<button>`, `<select>`, `<option>`, `<label>`, `<fieldset>`, `<legend>`

#### Metadata Tags
- Provide information about the document
- Examples: `<meta>`, `<title>`, `<link>`, `<style>`, `<script>`, `<base>`

### By Display Behavior:

- Start on a new line and take up full width available

#### Inline Tags
- Don't start on a new line and only take up necessary width
- Examples: `<span>`, `<a>`, `<strong>`, `<em>`, `<img>`, `<input>`, `<label>`, `<code>`, `<small>`

## Important Tag Characteristics

### 1. Tags are Predefined
- You cannot invent your own tag names in standard HTML
- Each tag has a specific meaning defined by HTML specification
- Browsers know how to interpret these predefined tags
- Custom tags require special frameworks (like Web Components)

### 2. Tags are Case-Insensitive
- `<HTML>`, `<html>`, and `<HtMl>` are all the same
- However, lowercase is the standard convention
- Best practice: Always use lowercase for consistency and readability

### 3. Tags Must Use Angular Brackets
- Tags must be enclosed in `<` and `>`
- Without brackets, text is displayed as regular content
- Example: "p" is just text, but `<p>` is a tag

### 4. Tags Can Have Attributes
- Attributes provide additional information about elements
- Written inside the opening tag
- Format: `<tagname attribute="value">`
- Example: `<img src="photo.jpg" alt="A photo" width="500">`

### 5. Tags Can Be Nested
- Tags can be placed inside other tags
- Must be closed in reverse order of opening
- Creates hierarchical structure
- Correct: `<div><p>Text</p></div>`
- Incorrect: `<div><p>Text</div></p>`

## Why Tags Use Angular Brackets
- Distinguish tags from regular text content
- Signal to browser: "this is an instruction, not content"
- Without brackets, tag names would display as text
- `<` and `>` are reserved characters in HTML for this purpose

## Summary
- **Paired Tags**: Have opening and closing tags, wrap content (`<p>content</p>`)
- **Self-Closing Tags**: Stand alone, no closing tag needed (`<br>`, `<img>`)
- **Comment Tags**: For notes and documentation, not displayed (`<!-- comment -->`)
- All tags use angular brackets and are predefined by HTML specification
- Tags can be classified by function (structural, formatting, media, etc.) or display behavior (block vs inline)
- Proper use of tags creates well-structured, semantic, and accessible webpages
